# news-image-20261121

One image that sums up the world news of **Saturday, 21 November 2026** —
a front page drawn with vector shapes and text (PIL, no network, no external
images). `generate.py` draws it; `main.ts` copies the bundled `entry.png`
to the output directory.

- **Lead:** Iran strikes two U.S. bases in Bahrain; Bahrain reports a fire
  at a civilian industrial site.
- **Ukraine:** a Russian missile hits Kryvyi Rih, Zelenskyy's hometown —
  2 killed, 60 wounded; missiles also land in Poland.
- **Mexico:** FBI most-wanted cartel boss "El Chapo Isidro" captured in
  Sinaloa; 11 dead in the backlash.
- **Climate:** COP31 talks in Antalya run into overtime with no deal.
- **Diplomacy:** Trump, Xi and Putin sign a peace pact in Shenzhen that
  says nothing about Ukraine.
- **Justice:** the World Court finds Myanmar guilty of genocide against
  the Rohingya — the first state ever found guilty.
- **Markets:** an AI sell-off erases the Nasdaq's 2026 gains; Anthropic
  debuts as a $2 trillion company.
- **Also:** Harden scores 51 and passes Kobe; a 6.9 quake shakes Peru.

`main.ts` (Node 22, standard library only) copies the bundled `entry.png`
to the output directory. Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
